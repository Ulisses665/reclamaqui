## 1. Visão Geral

Este é um projeto em Next.js com Typescript e Tailwind CSS.
O objetivo e criar uma aplicação que o aluno possa fazer uma reclamação.

## 2. Tecnologias

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui (quando necessário)

## 3. Como Executar

'''bash
npm install
npm run dev
'''
